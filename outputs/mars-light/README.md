# Mars Light

This is a child theme for the Rhye parent theme supplied with the project. It keeps existing WordPress posts, Elementor content, and menu assignments intact while changing the visual layer and removing the largest nonessential front-end interactions.

## Install

1. Keep **Rhye** installed; do not replace or edit it.
2. Zip the `mars-light` folder, then upload it in **Appearance → Themes → Add New → Upload Theme**.
3. Activate **Mars Light** and clear any cache/minification plugin cache.
4. In **Appearance → Customize → Theme Options**, turn off preloader, smooth scroll, AJAX transitions, and cursor follower if their stored settings override the defaults.

## What changes

- Replaces theatrical animation behavior with a static, fast-loading presentation.
- Makes navigation, project details, metadata, and next-project links more editorial and legible.
- Keeps the existing black-and-ivory visual vocabulary, with a restrained red accent drawn from Retro Red Light.
- Uses a responsive two-column metadata grid that becomes two columns on phones.

## Important

The WordPress export includes the published content, but it does not contain uploaded media files. Import it on the production site or use the importer's media-download option when available. Existing Elementor templates are intentionally left untouched.
